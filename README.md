# 🧠 Nexus - AI Research Agent

Nexus is an AI-powered research assistant built using Streamlit and Groq.

## Features

- Multiple Research Modes
  - Beginner Explanation
  - Detailed Research
  - Exam Preparation
  - Technical Explanation

- Suggested Topics
- Copy Response
- Clean Modern UI
- Context-Aware Responses
- Groq Llama 3.1 Integration

## Tech Stack

- Python
- Streamlit
- Groq API
- HTML/CSS

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
